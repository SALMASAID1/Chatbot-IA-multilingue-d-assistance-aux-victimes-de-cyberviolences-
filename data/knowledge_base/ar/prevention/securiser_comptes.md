# دليل الوقاية : تأمين حساباتك على الإنترنت

## لماذا يجب تأمين حساباتك؟
الحساب غير المحمي هو البوابة الرئيسية للمجرمين الإلكترونيين. بخطوات بسيطة، يمكنك تقليل مخاطر الاختراق والعنف الإلكتروني بشكل كبير.

## الخطوة 1 : إنشاء كلمات مرور قوية (باسوورد قوي)

### قواعد كلمة المرور الجيدة
- **12 حرفاً كحد أدنى** (الأفضل 16).
- امزج بين **أحرف كبيرة**، **صغيرة**، **أرقام** و**رموز خاصة** (!@#$%^&*).
- **لا تستخدم أبداً** : اسمك، تاريخ ميلادك، رقم هاتفك، أو كلمات بسيطة مثل « password » أو « 123456 ».
- **كلمة مرور مختلفة لكل حساب.** إذا اكتشف قرصان كلمة مرور بريدك الإلكتروني، لا يجب أن يتمكن من الوصول إلى فيسبوك.

## الخطوة 2 : تفعيل المصادقة الثنائية (2FA)

المصادقة الثنائية تضيف طبقة حماية إضافية. حتى لو سرق شخص كلمة مرورك، لن يتمكن من تسجيل الدخول بدون الرمز المؤقت المرسل إلى هاتفك.

### كيفية التفعيل؟
- **فيسبوك** : الإعدادات → الأمان وتسجيل الدخول → المصادقة الثنائية.
- **إنستغرام** : الإعدادات → الأمان → المصادقة الثنائية.
- **واتساب** : الإعدادات → الحساب → التحقق بخطوتين.
- **جيميل** : myaccount.google.com → الأمان → التحقق بخطوتين.

## الخطوة 3 : التحقق من الأجهزة المتصلة

تحقق بانتظام من الأجهزة المتصلة بحساباتك. إذا رأيت جهازاً غير معروف، قم بفصله فوراً وغيّر كلمة المرور.

- **فيسبوك** : الإعدادات → الأمان → « أين سجلت الدخول ».
- **إنستغرام** : الإعدادات → الأمان → نشاط تسجيل الدخول.
