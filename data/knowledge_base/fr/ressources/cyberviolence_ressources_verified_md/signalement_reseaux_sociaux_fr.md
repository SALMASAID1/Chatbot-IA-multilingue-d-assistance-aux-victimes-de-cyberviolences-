# Guide vérifié : signaler une cyberviolence sur les réseaux sociaux

## Présentation

Le signalement permet d'alerter les plateformes lorsqu'un contenu, un message ou un compte enfreint leurs règles : harcèlement, menaces, usurpation d'identité, diffusion d'images intimes, exploitation sexuelle, contenus haineux ou contenus illicites.

Les interfaces changent régulièrement. Les étapes ci-dessous donnent la procédure générale vérifiée à partir des centres d'aide officiels des plateformes.

---

## Avant de signaler : préserver les preuves

Avant de bloquer ou signaler, il est recommandé de sauvegarder les preuves :

- captures d'écran complètes ;
- liens des profils, publications, vidéos ou commentaires ;
- dates et heures ;
- nom du compte, identifiant, numéro ou pseudonyme ;
- messages reçus ;
- si possible, téléchargement ou sauvegarde des fichiers problématiques sans les repartager.

> Attention : lorsqu'un contenu est signalé, il peut être supprimé par la plateforme. Sans preuve conservée, il peut devenir difficile de démontrer ce qui s'est passé.

---

## 1. Facebook

### Signaler une publication ou un contenu
1. Ouvrir la publication, photo, vidéo ou commentaire.
2. Cliquer sur les trois points ou l'option de menu.
3. Choisir **Signaler** ou **Trouver de l'aide ou signaler**.
4. Sélectionner la raison : harcèlement, menace, nudité, contenu haineux, usurpation, etc.
5. Suivre les instructions affichées.

### Signaler un profil
1. Aller sur le profil concerné.
2. Cliquer sur les trois points.
3. Choisir **Signaler le profil**.
4. Sélectionner la raison et envoyer le signalement.

---

## 2. Instagram

### Signaler une publication, story, reel ou commentaire
1. Ouvrir le contenu.
2. Appuyer sur les trois points ou maintenir le commentaire selon le type de contenu.
3. Choisir **Signaler**.
4. Sélectionner la raison appropriée.

### Signaler un profil
1. Ouvrir le profil.
2. Appuyer sur les trois points en haut à droite.
3. Choisir **Signaler**.
4. Suivre les instructions.

Instagram recommande de signaler les contenus abusifs directement via le lien de signalement proche du contenu.

---

## 3. TikTok

### Signaler une vidéo
1. Ouvrir la vidéo.
2. Appuyer sur le bouton **Partager** ou maintenir la vidéo.
3. Choisir **Signaler**.
4. Sélectionner une raison et envoyer.

### Signaler un compte
1. Aller sur le profil du compte.
2. Appuyer sur le bouton de partage ou le menu.
3. Choisir **Signaler** puis **Signaler le compte**.
4. Sélectionner la raison.

TikTok permet aussi de signaler des commentaires, messages directs, lives, hashtags, comptes d'usurpation et certains cas de cyberharcèlement visant des enfants.

---

## 4. WhatsApp

### Signaler un contact ou un numéro inconnu
1. Ouvrir la conversation avec le contact ou le numéro.
2. Aller dans les options de la conversation.
3. Choisir **Plus** puis **Signaler**, ou **Bloquer et signaler** selon l'appareil.
4. Confirmer le signalement.

### Signaler un groupe
1. Ouvrir le groupe.
2. Appuyer sur le nom du groupe.
3. Chercher l'option **Signaler le groupe**.
4. Confirmer.

WhatsApp indique que l'on peut signaler un contenu problématique et bloquer une personne pour ne plus recevoir ses messages, appels ou statuts.

---

## 5. Snapchat

### Signaler un Snap, un message ou un contenu
1. Maintenir appuyé sur le contenu ou le message.
2. Choisir **Report / Signaler**.
3. Sélectionner la raison.
4. Envoyer le signalement.

### Signaler un compte
1. Ouvrir l'écran de discussion.
2. Maintenir appuyé sur le nom de la personne.
3. Choisir **Manage Friendship / Gérer l'amitié**.
4. Appuyer sur **Report / Signaler**.

Snapchat recommande aussi de bloquer la personne et de parler à un parent ou un adulte de confiance en cas de harcèlement.

---

## 6. Signalement au Maroc en plus de la plateforme

Le signalement sur Facebook, Instagram, TikTok, WhatsApp ou Snapchat ne remplace pas un signalement auprès des autorités lorsqu'il y a infraction ou danger.

### E-Blagh — DGSN
- Pour signaler un contenu illicite publié sur Internet : https://e-blagh.ma/

### Cyberconfiance / eVigilance
- Pour demander de l'aide, une orientation ou signaler une cyberviolence :
  - https://www.cyberconfiance.ma/
  - https://evigilance.ma/

### Urgence
- Police : **19**
- Gendarmerie Royale : **177**
- Protection Civile : **15**
- ONDE pour les enfants : **2511** ou **0800002511**

---

## 7. Conseils importants

- Ne répondez pas aux menaces si cela vous met en danger.
- Ne payez pas un maître-chanteur.
- Sauvegardez les preuves avant le signalement.
- Bloquez l'agresseur après avoir conservé les preuves.
- Prévenez une personne de confiance.
- Si la victime est mineure, contactez rapidement un adulte responsable, l'ONDE ou les autorités.
- Si des images intimes sont diffusées, signalez immédiatement le contenu sur la plateforme et demandez une aide spécialisée.
