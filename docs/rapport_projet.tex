\chapter{Introduction Générale}
% ============================================================

\section{Contexte du projet}

Le Centre Marocain de Recherches Polytechniques et d'Innovation (CMRPI), à travers son initiative \textbf{Espace Maroc Cyberconfiance (EMC)}, s'engage activement dans la protection des citoyens marocains contre les cyberviolences. Dans ce cadre, le projet EMC Helpline vise à offrir une assistance numérique accessible, confidentielle et disponible 24h/24 aux victimes de cyberviolences.

Les cyberviolences -- harcèlement en ligne, cyberbullying, chantage numérique, diffusion non consentie d'images intimes, usurpation d'identité numérique -- constituent une menace croissante qui touche particulièrement les jeunes et les femmes au Maroc. Face à l'insuffisance des dispositifs d'accompagnement existants, un assistant conversationnel intelligent représente une solution innovante pour combler ce vide.

\section{Problématique}

Comment concevoir un chatbot intelligent, multilingue (arabe et français), capable de :
\begin{itemize}[noitemsep]
    \item Comprendre et classifier les situations de cyberviolences rapportées par les victimes ?
    \item Fournir des réponses empathiques, précises et adaptées au contexte marocain ?
    \item Orienter les victimes vers les ressources compétentes (juridiques, psychologiques, policières) ?
    \item Fonctionner de manière autonome 24h/24 grâce à l'IA générative ?
\end{itemize}

\section{Objectifs du projet}

\begin{enumerate}[noitemsep]
    \item Développer un \textbf{chatbot multilingue} supportant l'arabe (dont le darija) et le français.
    \item Intégrer un \textbf{moteur d'IA générative} (LLM) avec une architecture RAG (Retrieval-Augmented Generation).
    \item Construire une \textbf{base de connaissances} spécialisée sur les cyberviolences au Maroc.
    \item Fournir des \textbf{réponses adaptées} incluant l'orientation vers les ressources compétentes.
    \item Concevoir une \textbf{interface utilisateur} accessible et responsive.
    \item Assurer la \textbf{confidentialité} et la \textbf{sécurité} des données des utilisateurs.
\end{enumerate}

\section{Analyse de l'existant}

Avant d'entamer le développement, une analyse approfondie des solutions existantes est nécessaire :

\subsection{EMC Chatbot Beta}
La version Beta accessible à \url{https://emc-chatbot.vercel.app/} est un prototype initial développé en Next.js. Elle présente une interface minimaliste de chat avec les caractéristiques suivantes :
\begin{itemize}[noitemsep]
    \item Interface en anglais uniquement
    \item Fonctionnalités conversationnelles basiques
    \item Absence de base de connaissances spécialisée
    \item Pas de support multilingue (arabe/français)
\end{itemize}

\subsection{Plateforme eVigilance}
La plateforme \url{https://evigilance.ma/fr} (HELPLINE -- Ligne Nationale d'assistance) est un portail Angular complet développé par le CMRPI offrant :
\begin{itemize}[noitemsep]
    \item Des informations sur les différents types de cyberviolences
    \item Un système de signalement en ligne
    \item Des ressources d'aide et d'orientation
    \item Un design professionnel avec support multilingue
\end{itemize}

\subsection{CyberEConfiance}
Le site \url{https://www.cybereconfiance.ma} représente la plateforme institutionnelle du CMRPI pour la confiance numérique au Maroc.

\section{Architecture RAG détaillée}

Le processus RAG fonctionne en plusieurs étapes :

\begin{enumerate}
    \item \textbf{Ingestion} : Les documents de la base de connaissances (textes juridiques, guides psychologiques, ressources CMRPI) sont découpés en chunks et vectorisés.
    \item \textbf{Indexation} : Les vecteurs sont stockés dans ChromaDB/Pinecone avec leurs métadonnées (langue, catégorie, source).
    \item \textbf{Recherche} : À chaque question utilisateur, une recherche sémantique retrouve les documents les plus pertinents.
    \item \textbf{Augmentation} : Le contexte retrouvé est injecté dans le prompt envoyé au LLM.
    \item \textbf{Génération} : Le LLM génère une réponse contextualisée, empathique et précise.
\end{enumerate}

\chapter{Base de Connaissances}

\section{Sources de données}

La base de connaissances sera construite à partir des sources suivantes :

\begin{itemize}
    \item \textbf{Cadre juridique marocain} : Lois relatives à la cybercriminalité (Loi 103-13, Code pénal -- articles sur le harcèlement numérique).
    \item \textbf{Ressources CMRPI} : Documentation officielle d'eVigilance et CyberEConfiance.
    \item \textbf{Guides psychologiques} : Protocoles d'accompagnement des victimes de cyberviolences.
    \item \textbf{Annuaire de ressources} : Contacts des services compétents (police, associations, lignes d'écoute).
    \item \textbf{FAQ} : Questions fréquemment posées par les victimes.
\end{itemize}

\chapter{Scénarios Conversationnels}
% ============================================================

\section{Flux conversationnel principal}

\begin{enumerate}
    \item \textbf{Accueil} : Message de bienvenue multilingue, choix de la langue.
    \item \textbf{Identification du besoin} : Questions guidées pour comprendre la situation.
    \item \textbf{Classification} : Détection automatique du type de cyberviolence.
    \item \textbf{Réponse} : Informations adaptées, conseils pratiques.
    \item \textbf{Orientation} : Redirection vers les ressources compétentes.
    \item \textbf{Suivi} : Résumé et propositions de ressources complémentaires.
\end{enumerate}

\section{Exemple de scénario -- Cyberharcèlement}

\begin{lstlisting}[language={},caption={Exemple de conversation}]
Bot: Bienvenue sur EMC Helpline. Je suis ici pour vous
     aider. En quelle langue souhaitez-vous continuer ?
     (Francais / Arabe)

User: Francais

Bot: Je suis la pour vous ecouter. Pouvez-vous me decrire
     brievement votre situation ?

User: Je recois des messages menacants sur Instagram.

Bot: Je comprends que cette situation est difficile.
     Recevoir des menaces en ligne est une forme de
     cyberharcelement punie par la loi marocaine.
     Voici ce que je vous recommande :
     1. Conservez des captures d'ecran des messages
     2. Bloquez le compte en question
     3. Signalez a la plateforme
     4. Deposez une plainte [lien vers procedure]
     Souhaitez-vous plus de details sur l'un de ces points ?
\end{lstlisting}
