# Tâche 1 — Analyse de l'existant et étude comparative

## Assigné à
**Salma Said** & **Mohamed Tamzirt** (travail collaboratif)

## Objectif
Réaliser une analyse approfondie des solutions existantes (EMC Chatbot Beta, eVigilance, CyberEConfiance) et des chatbots d'assistance similaires dans le monde, afin de définir les forces, faiblesses et axes d'amélioration pour le nouveau chatbot.

## Étapes d'implémentation

1. **Explorer le chatbot Beta** (https://emc-chatbot.vercel.app/)
   - Tester toutes les fonctionnalités existantes
   - Documenter les points forts et les limites
   - Analyser le code source si disponible (architecture Next.js)

2. **Analyser la plateforme eVigilance** (https://evigilance.ma/fr)
   - Étudier la structure de contenu et les catégories de cyberviolence
   - Identifier les ressources et données réutilisables
   - Analyser le système de signalement

3. **Benchmark des chatbots d'assistance existants**
   - Rechercher des chatbots similaires (lignes d'assistance, santé mentale)
   - Comparer les approches conversationnelles
   - Identifier les bonnes pratiques UX pour les victimes

4. **Rédiger le rapport d'analyse**
   - Document synthétique avec matrice SWOT
   - Recommandations techniques et fonctionnelles

## Outils et ressources
- Navigateur web pour les tests
- Google Docs / Markdown pour la documentation
- Outils de capture d'écran (pour documenter les interfaces)
